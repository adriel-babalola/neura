# Remove vibe-coded UI indicators

Strips the telltale signs of AI-generated UI from the Neura marketing and onboarding pages: emoji icons replaced with lucide-react components, em-dashes converted to commas, fabricated trust stats replaced with factual claims, "Powered by Gemini" badges removed, and the New Lesson layout given responsive width breakpoints. The change touches six files across landing, signin, onboarding, parent dashboard, lesson view, and the TTS route comment.

**Watch for:** The em-dash-to-comma swap introduces grammatical awkwardness in several sentences that previously relied on the dash as parenthetical punctuation (confirmed). The age indicator renders JSX inside a `<span className="text-sm">` which works but loses the inline text sizing the emojis had (confirmed, minor). No functional regressions otherwise.

**Verdict**: APPROVED

## High-level view

The emoji-to-icon migration is clean: each emoji was backed by an unused lucide icon in the old code (interests had both `icon` and `emoji` fields), so the swap simply drops the emoji field and renders the icon that was already imported. The signin page had a worse version of this — both an emoji *and* an icon rendered — and now only the icon remains.

The "Powered by Gemini" badges on the landing page hero and the parent settings sidebar are deleted entirely. The trust stats below the hero CTA are replaced with claims the product can actually back ("Adaptive AI tutoring", "Child-safe by design", "No data stored remotely", "Free to start") — a meaningful improvement over fabricated numbers.

The em-dash replacement is a blanket find-and-replace (including in code comments and JSX title attributes). Most substitutions read fine, but a few produce comma splices where the original dash served as parenthetical punctuation, making the sentences slightly harder to parse. This is cosmetic, not blocking.

The responsive layout change on the parent page's "create lesson" view adds `xl:max-w-5xl 2xl:max-w-6xl` alongside the existing `max-w-4xl`, plus a wider grid gap. This lets the form breathe on larger screens without affecting mobile.

## Comma-for-dash substitution and readability

The diff replaces every em-dash (`—`) with a comma across all user-facing strings and code comments. In short phrases ("Start free, no credit card") this reads naturally. In longer sentences the comma creates run-ons:

```
Neura learns who your child is, their interests, how they think, and where they
struggle, then builds a lesson just for them.
```

The original used paired dashes to parenthetically set off "their interests, how they think, and where they struggle" — removing the dashes collapses the clause boundaries. Similarly, "This shapes how Neura speaks, a 7-year-old and a 12-year-old get very different lessons" is now a comma splice joining two independent clauses.

A targeted fix (periods or semicolons for the multi-clause sentences, commas for the short ones) would read better than a blanket substitution.

## Age indicator dead class

The age indicator swaps inline emoji strings for JSX icon components inside the ternary. Because these are now React elements rather than text, the containing `<span className="text-sm">` no longer influences their visual size — SVGs ignore inherited font-size. The explicit `h-4 w-4` on each icon handles sizing directly, making the `text-sm` class inert. Removing it (or changing the span to a `div` with flex alignment) would better reflect the new content type.
